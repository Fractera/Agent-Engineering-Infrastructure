# Голосовой ввод — микросервис (рантайм/продакшн-слой)

Первая фича, переехавшая на архитектуру «микросервис» (шаг 298): всё, что относится к голосовому вводу, лежит
в ОДНОЙ папке — ничего не разбросано.

```
voice-input/
  client/   voice-input.client.tsx   — сам компонент (кнопка-микрофон, полоса звука, вставка по курсору)
            voice-input-i18n.ts       — 10 языков
  server/   transcribe.ts             — серверная функция расшифровки (OpenAI); дверь api/transcribe = тонкая обёртка над ней
  types/    voice-input.ts            — общий контракт client/server (пропсы + результат расшифровки)
```

**Продакшн-роль:** это РАНТАЙМ-примитив конечного пользователя — им голосом делают запросы в публичном пульте
(`control-panel/public/.../param-field`). Живёт в папке автоматизации (закон устойчивости: продакшн твёрдый),
зависит только от своих файлов, `api/transcribe` бьётся ОТНОСИТЕЛЬНЫМ путём (папка = архив, закон 0).

Дев-версия того же примитива (для кнопки «Строить вместе с ИИ») — снаружи, в `_shared-v2/tools/voice-input/`.
