# Диаграмма — public/ намеренно пуст

У диаграммы в папке автоматизации СВОЕГО кода нет вовсе: холст, его кнопки и адаптер `graph → вью-модель`
живут ОДНОЙ копией в административном слое `_shared-v2/components/diagram/{client,server,types}` и
одинаковы для всех автоматизаций в любом аккаунте.

Папка `public/` существует, чтобы раскладка сущности была ЕДИНОЙ со всеми остальными (`index.tsx` +
`public/` + `admin/`).

🔒 Почему так (решение владельца 2026-07-24): диаграмма — ПЛАТФОРМЕННЫЙ ВИД над ядром, а не фича этой
автоматизации. Копия в каждой папке = N расходящихся копий; «улучшил» в одной — она несовместима с
остальными, и переиспользование между аккаунтами ломается.

**Агенту-кодеру править код диаграммы ЗАПРЕЩЕНО** (`AGENTS.md` §0a). Он владеет только ДАННЫМИ:
`graph.nodes` и `graph.edges` в ядре, через `api/patch`. Меняются данные — вид следует сам.
