# Предупреждения — public/ намеренно пуст

Публичной половины у этой сущности нет: предупреждение агента — внутренняя правда ВЛАДЕЛЬЦА о ходе
разработки, посетителю витрины показывать её нечего.

Папка существует, чтобы раскладка сущности была ЕДИНОЙ со всеми остальными (`index.tsx` + `public/` +
`admin/`) — у Центра проблем она устроена так же, как у календаря, а не особым случаем.

Вся суть живёт в микросервисе `_shared-v2/components/warnings/{client,server,types}`; в `admin/` — только
тонкий монтаж через fail-silent дев-слот.
