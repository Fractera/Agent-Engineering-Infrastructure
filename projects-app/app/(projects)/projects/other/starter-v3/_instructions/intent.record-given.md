# CLASS `record-given` — the data is already here and only needs keeping

> **Law of instructions: ENGLISH, COMPACT, one fact one home.** Its reader is a model that must read the core too, so every line here is paid on every session. Prune before you append; never restate what another instruction already says — link to it by name.

**Where the answer lives:** in the message itself. **Routes to:** the middle, which normalizes it, and then
the stores.

«The meeting moved to Friday.» Nothing to fetch, nothing to look up — a fact was stated and it should
survive.

## Why it stands LAST among the content classes

It is the widest of them: almost anything that is not a question could be kept. Standing last means every
narrower class has already had its chance, so «wide» never means «greedy». Precedence is the order of the
class nodes in the core — this class relies on it, and moving it up would quietly break every class below.

## How it recognizes

🔒 By POSITIVE recognition, never by exclusion. Cheap negatives first (empty, one word, an obvious question),
then the request must be READ as a record — no reading, no claim. Until step 312.6 this class took everything
that was not an English question: it WAS the silent default the front law forbids, and a Russian request for a
password landed in the database. Losing a record is safer than storing what nobody asked to store. The
intelligence stays in the middle: it decides what kind of record it is and which stores it touches.

## What it must never do

- **Never write here.** It hands the text on. Writing from a front node is the v2 defect the whole layer
  exists to end.
- **Never interpret the fact.** Parsing amounts, dates and places is the middle's work; guessing them here
  puts a second parser in the wrong layer.
- **Never claim a question.** If it ends in a question mark or opens with an interrogative, it is not this
  class — no matter how much it also states.

## Reuse

Domain-neutral. What a record means differs everywhere; that a human will state facts does not.
