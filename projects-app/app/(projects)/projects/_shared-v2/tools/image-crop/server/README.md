# `image-crop/server` — намеренно пуст

У инструмента обрезки изображения серверной части нет: кадрирование целиком происходит в браузере на
`<canvas>`, и готовый JPEG-blob возвращается вызывающему коду через колбэк `onDone`. Ни расшифровки, ни
загрузки, ни модели — сервер не участвует.

Папка `server/` существует, чтобы раскладка инструмента была ЕДИНОЙ с остальными микросервисами
`_shared-v2/tools/*` (`client` + `server` + `types`), как у `voice-input`.

Куда положить готовый кадр (объектное хранилище склада и т.п.) — решает тот, кто подключил инструмент, уже
своей серверной дверью; сам инструмент об этом не знает.
