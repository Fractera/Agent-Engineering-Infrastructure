# Голосовой ввод (дев-слой) — server/ намеренно пуст

У дев-версии голоса СВОЕЙ серверной функции нет: дев-кнопка «Строить вместе с ИИ» рендерится ВНУТРИ
страницы автоматизации (через дев-слот), поэтому её голосовой примитив бьёт в ту же дверь `api/transcribe`
самой автоматизации — а её серверная функция живёт в рантайм-микросервисе
`other/<автоматизация>/_components/tools/voice-input/server/transcribe.ts`.

Одна серверная функция расшифровки на фичу, не разбросана. Здесь — только клиент (`client/`) и типы (`types/`).
