# Пульт запуска (админ-половина, дев-слой) — server/ намеренно пуст

У админ-настройки пульта СВОЕЙ серверной функции нет: она читает объявление формы из ядра САМОЙ
автоматизации через её собственную дверь чтения — `GET api/core?select=tab:control-panel` (относительным
путём от адреса страницы). Одна дверь на всё ядро, второго читателя объявления не заводим.

Здесь — только клиент (`client/`) и типы (`types/`). Публичный рантайм пульта (сама форма, отправка
запроса, отчёт о прогоне) живёт В ПАПКЕ автоматизации — `_components/control-panel/public/` — и работает
без этого слоя.
