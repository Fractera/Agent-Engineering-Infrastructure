# Диаграмма (дев-слой) — server/ намеренно пуст

У диаграммы СВОЕЙ серверной функции нет: она читает граф и компоненты из ядра САМОЙ автоматизации через
её собственную дверь чтения — `GET api/core?select=graph` и `?select=components`. Одна дверь на всё ядро,
второго читателя графа не заводим.

Адаптер `client/graph-to-flow.ts` — чистая функция над этими данными (ядро → вью-модель холста); он тоже
клиентский, потому что и холст клиентский.

🔒 Диаграмма — ПЛАТФОРМЕННЫЙ ВИД: одна копия на все автоматизации, агенту-кодеру её код править запрещено
(`AGENTS.md` §0a). Он меняет только данные — `graph.nodes` / `graph.edges` через `api/patch`.
