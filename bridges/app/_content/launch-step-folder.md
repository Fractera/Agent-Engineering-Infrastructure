Create a **separate, empty folder** on your computer — for this project only. The
repository will land there, and the agent will work there.

> **Do not skip this.** The classic mistake most developers make is starting the project
> inside a shared workspace, among a dozen unrelated folders. The agent sees everything
> nearby, and its attention is spent on other people's code: quality drops, errors
> multiply, and the cause stays invisible. A separate folder costs one minute and saves
> weeks.

Give it a clear name — your project's name, for instance. Remember the path: you will
need it in the next step.

Tick the box once the folder exists.
