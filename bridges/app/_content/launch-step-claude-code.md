From here the project is built by a **programming agent**, and you direct it. You need
Claude Code.

**If you are starting out — use the web version.** It opens in a browser, nothing to
install, and you pick the project folder inside it. It requires a **paid developer
subscription**; without one the agent will not start.

**If you have worked in a terminal before** — Claude Code in the command line plus your
own editor. This is the professional mode: same agent, more control, higher barrier.

The application exists for both Windows and macOS. Install the one that fits your machine.

Tick the box once Claude Code is open and the subscription is paid.
