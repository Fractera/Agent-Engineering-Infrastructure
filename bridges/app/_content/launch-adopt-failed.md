### The build did not pass

There is some architectural mismatch — or you have connected a project that is not part of
the Fractera architecture.

If your project was created with a different framework, or it is built on Next but **not
on the Fractera architecture**, you need the **migration process**. It lets you use the
starter template and, with a dedicated algorithm, skills and tools, transform your project
into the Fractera architecture so development can continue.

Below are two paths: restore the starter template and take the normal launch route, or
write to us and have Fractera carry the project over.
