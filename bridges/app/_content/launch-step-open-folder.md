Start Claude Code. On launch it will offer to **choose the project folder** — point it at
the one you just created. This matters: the agent works in the folder you named and in no
other.

**Make sure you did not miss.** Ask the agent, word for word:

> Which folder are you working in right now? Give me the full path.

Compare the answer with your folder's path. A match means you are set. No match — close
Claude Code and reopen it, choosing the right folder; continuing in the wrong one is not
an option.

Tick the box once the agent named the correct path.
