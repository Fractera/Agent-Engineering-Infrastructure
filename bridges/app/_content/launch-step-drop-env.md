Open your file explorer, find the downloaded `.env.local` and **drag it straight into the
Claude Code window** — with the mouse, like any other file. Then send a message and ask
the agent:

> Did you receive the `.env.local` file? Can you start installing dependencies now?

Wait for confirmation. The agent should say it has the file and is ready to install
packages — only then is the step done.

If the agent does not see the file, drag it again: sometimes a file gets dropped beside
the window rather than into it.

Tick the box: I have confirmation that Claude Code is ready to install dependencies.
