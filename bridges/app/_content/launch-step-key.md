The programming agent works on **your** machine, not here. To let it reach this
server — read logs, deploy, restart services — it needs a key.

Press the orange button. The key is created here, on your server, and its private
half leaves exactly once: into the file you download.

**The root password is never handed out.** The key gives the same level of access,
is not printed in logs, and is revoked with one line if you ever need to.
