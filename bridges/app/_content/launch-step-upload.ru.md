Отправьте проект в репозиторий, который только что подключили. Пока этого не
произошло, на GitHub лежит пустая оболочка, а ваш код по-прежнему в одном месте.

Нажмите **отправить проект**, дождитесь конца, затем нажмите **проверить проект**.
Панель спрашивает у GitHub напрямую, есть ли на ветке `main` коммит, — а не то,
нажимали ли кнопку. Отправка умеет падать тихо; ответ GitHub — нет.
