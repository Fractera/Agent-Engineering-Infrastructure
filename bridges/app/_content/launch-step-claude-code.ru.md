Дальше проект строит **агент-программист**, а вы им управляете. Нужен Claude Code.

**Для начинающих — веб-версия.** Она открывается в браузере, ничего ставить не нужно,
и папку проекта вы выбираете прямо в ней. Потребуется **оплаченная подписка
разработчика** — без неё агент не запустится.

**Для тех, кто уже работал с терминалом** — Claude Code в командной строке плюс ваш
редактор. Это режим для профессионалов: тот же агент, больше контроля, выше порог входа.

Приложение существует и для Windows, и для macOS. Ставьте ту версию, которая подходит
вашей машине.

Отметьте галочку, когда Claude Code открыт и подписка оплачена.
